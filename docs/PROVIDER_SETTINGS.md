# DeepSeek 连接状态与手动配置

界面右上角提供 DeepSeek 状态和 API 配置入口。状态区分未配置、已配置待检测、连接检测结果、检测过期及停用；配置存在不代表服务在线。

## 配置行为

当前登录账号可以保存或更换 API 密钥、修改模型、恢复服务端默认配置，或停用 DeepSeek。密钥输入框不回显已保存值，留空表示保留现有可用密钥。配置保存后用于后续分析，已开始的请求保留开始时的配置。

配置保存在当前运行环境的服务端。本机和线上站点分别保存，互不自动同步。个人配置按账号隔离；默认配置来自服务器运行时设置。恢复默认会移除个人覆盖。停用保留加密密钥和模型，可通过留空密钥再次保存启用；停用期间保留规则方案和法律核对功能。

API 地址固定为 `https://api.deepseek.com`，不能由表单或案件材料改变。模型名称可以手动填写，检测时核对官方接口实际返回的模型列表；模型支持图片与否以可用的官方能力元数据为准。

## 连接检测

检测只针对已保存配置，编辑内容未保存时先保存再检测。服务端向官方 [`GET /models`](https://api-docs.deepseek.com/api/list-models/) 发起鉴权请求，不上传案件、附件或对话，也不调用生成接口。

连接正常仅表示本次网络、鉴权和所选模型检查成功，不保证后续每次生成成功或账户额度充足。界面展示最近检测时间和响应耗时；过期结果不持续当作实时在线。错误状态使用预设文字区分鉴权、额度、限流、超时、服务不可用和模型不存在等情况，不展示上游原始错误信息。[DeepSeek 官方错误码说明](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)

检测设有超时、响应大小、缓存、频率与并发限制，拒绝跟随重定向。配置更新时旧检测结果失效，在途的旧结果不能覆盖新配置状态。

## 保存方式

个人密钥使用 AES-256-GCM 加密后保存到数据库，并与账号绑定。线上加密主密钥由独立的 Sites runtime Secret `AI_CONFIG_ENCRYPTION_KEY` 提供；应用不会将其写入源码、构建产物或前端。

本机使用独立、稳定的加密主密钥。Windows 下由当前用户 DPAPI 保护并保存到 `.local-data`；其他平台使用限制权限的本地文件，或通过进程变量提供主密钥。该文件和数据库须一并备份。已有加密主密钥损坏时不自动重新生成，以免将原密钥永久变成不可读。

浏览器不保存密钥到 localStorage、sessionStorage、URL或报告。服务端状态接口只返回配置来源、模型、版本及检测状态，不返回密钥片段、密文或内部错误。保存采用版本检查，冲突时保留用户当前输入并要求重新核对后主动保存。
