# 回款方案版本删除

“回款方案”工具栏可删除当前选中的方案版本。确认框标明案件和版本，仅修改该版本的可见状态。案件基本信息、附件、跟进记录、应收台账和其他方案版本继续保留。

删除后该版本从正常版本选择、方案内容、导出和打印中移除。其生成时的案情、材料清单和法律依据快照仍留存，可在同一案件的“已删除方案”中恢复。删除最后一个可用版本后显示空状态，恢复入口继续可用。

版本编号按包含已删除记录的完整生成顺序显示，删除某版不会给其他版本重新编号。删除和恢复只更新该方案的状态版本，不改变案件资料版本或保存未提交的表单。

归档案件保持只读，恢复案件后再删除或恢复方案。生成和写入期间禁用冲突操作。界面确认对象固定为当时选择的案件及方案，避免切换记录后误操作；取消确认不会提交删除请求。

服务端同时检查登录账号、案件、方案及状态版本。重复执行相同状态操作可安全返回，过期的反向操作须重新读取。数据库使用 `deleted_at` 与 `state_version` 保存可恢复状态，不物理删除方案或附件。前端按状态版本合并异步结果，旧的生成响应不能重新显示已删除版本。

本功能用于整理方案列表，属于可恢复删除；永久删除、数据保留期限和合规清理不在本次范围内。
