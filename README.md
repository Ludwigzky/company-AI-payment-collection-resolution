# 应收账款管理平台

面向企业内部回款工作的案件工作台。每个案件独立保存基础资料、原始附件、方案版本和跟进记录；界面采用深蓝顶栏、左侧历史与紧凑表单，支持设备销售维保、一般货款和工程结算。

## 当前功能

- 右上角 DeepSeek 状态与 API 配置：支持加密保存个人密钥、修改模型、检测已保存连接、停用与恢复默认，并展示检测时间和过期状态。
- 顶栏“应收总览”集中管理各案件的付款节点：开票、财务确认应收和付款到期分别登记；账龄与逾期分开统计，缺失依据保留待确认。
- 法律事项时间线分别保留发生、送达、录入、业务提醒与人工核定期限；更正追加留痕，不按欠款日期自动计算诉讼时效。
- 服务器历史记录，支持搜索、进行中与已归档筛选；可新建空草稿或明确标注的虚构示例。
- 信息不完整时也能保存，切换案件前自动保存；版本冲突保留当前填写内容并提示重新载入。
- 在表单旁上传文件、图片，预览图片、下载原件并选择本次分析材料。
- DeepSeek 接收本案件选中图片或文档提取内容，给出具体材料线索、缺口、回款建议和沟通草稿。
- 每次生成保留输入快照、资料版本、材料清单与识别限制；资料更新后保留旧方案并提示重新生成。
- 回款方案可按版本删除，并在“已删除方案”恢复；其他版本、案件和附件保留，删除后不会被旧的异步结果重新显示。详见[方案删除说明](docs/PLAN_DELETION.md)。
- 生成期间可以切换案件，结果归入原案件；跟进记录、草稿与导出也按案件隔离。
- 生成前按案件检索已核对的有限法条集；每项法律建议关联填报事实、完整法条、版本、官方链接、适用条件和证据缺口。依据不足或条件排除时保留核对理由，不给确定责任结论。
- 维修与商务安排标为业务建议；模型失败时保留法律条件核对与规则方案，不自动投诉、发函或提交程序申请。

## 材料支持

| 类型 | 处理方式 |
| --- | --- |
| PNG、JPEG、GIF、WebP | 原始图片由 DeepSeek 视觉模型读取 |
| PDF | 最多40页，逐页提取文字层；扫描或加密文件须转图片或重新导出 |
| DOCX | 提取段落文字，图片与签章须另上传图片 |
| XLSX | 提取表名、单元格位置、文字与公式缓存，不执行公式 |
| TXT、CSV、MD、JSON | 读取 UTF-8 原文 |

单个附件最多5MiB，每案最多8个、共16MiB；一次选中分析最多12MiB，提取文字合计最多40,000字符。超限或无法读取时明确报错，不静默当作已读。旧DOC/XLS、SVG、宏文件及未支持格式不接受。详见[材料分析说明](docs/MATERIAL_ANALYSIS.md)。

## 本地运行

需要 Node.js 24：

```powershell
npm ci
npm run dev
```

打开终端打印的本机地址，默认 `http://127.0.0.1:4173/`。本机启动时应用已提交迁移，将案件写入 `.local-data/records.sqlite`、原始附件写入 `.local-data/files/`；重启保留，目录不提交Git。本机只监听127.0.0.1，使用固定的本地预览用户，不代替线上认证。

本机默认配置读取进程变量 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`，不会自动加载 `.env`。也可通过页面右上角“API 配置”保存当前账号的手动配置，保存后立即用于后续分析。托管端默认配置继续使用 Sites runtime Secret；手动密钥经账号绑定的 AES-256-GCM 加密后保存，状态接口不回传密钥。缺少配置或停用模型时仍可保存案件并生成规则方案。详见[连接与配置说明](docs/PROVIDER_SETTINGS.md)。

## 线上存储与隔离

保留原站点私有访问配置，使用 D1 `DB` 保存记录、R2 `BUCKET` 保存原始附件；发布时应用 `drizzle/` 中的迁移。案件接口要求可信平台登录身份，每次读写同时约束用户、案件与相关附件。

附件没有公共链接，预览和下载经过案件权限检查。每次分析从当前案件读取选中附件，核查SHA-256后建立独立模型请求，不拼接其他案件历史。当前按登录账号隔离，尚未实现企业部门角色或跨账号共享。详见[案件存储说明](docs/RECORD_STORAGE.md)。

归档可以恢复，移除附件属于软移除，历史记录及原始文件保留；尚未实现永久删除和自动保留期限策略。

## 验证与构建

```powershell
npm test
npm run check
npm run build
```

`npm test` 先构建，再验证规则、模型、法律核对、材料、案件存储、总览、服务配置与Worker。当前234项通过、1项平台专属测试跳过；覆盖方案删除恢复、独立财务口径、法律时间线、账号隔离、密钥加密、配置版本与探测竞态、实际分析路由凭据选择及原有生成链路。另完成总览、服务配置和方案删除的内存DOM/API检查，未替代实际浏览器视觉验收。修改表结构时运行 `npm run db:generate`，提交SQL和Drizzle元数据；已应用迁移不可改写。

本机浏览器已验证企业界面、案件创建和文件图片上传。线上已使用获授权的虚构案件完成TXT与PNG真实分析，图片中的设备问题、待签字和复验节点被分别列出；第二案件未带入第一案件的附件和方案。最终刷新留存与测试归档记录见项目上级验收文档。

## 关键文件

| 文件 | 责任 |
| --- | --- |
| `dist/index.html`、`styles.css`、`app.js` | 企业界面与记录级异步状态 |
| `src/workspace-api.js`、`records.js` | 案件、附件、历史方案、备注和归属校验 |
| `src/materials.js` | 类型、大小、文档提取及图片上下文 |

| `dist/overview.js`、`src/overview-store.js`、`src/overview-metrics.js` | 总览界面、节点与事件持久化、独立金额与日期统计 |
| `dist/provider.js`、`src/provider-settings.js`、`src/provider-probe.js` | DeepSeek 配置入口、账号加密设置及连接检测 |
| `src/local-provider-key.mjs` | 本机稳定加密主密钥及 Windows DPAPI 保护 |
| `db/schema.js`、`drizzle/` | 数据模型与不可变迁移 |
| `src/local-storage.mjs`、`server.mjs` | 本机SQLite及文件存储 |
| `worker/index.js`、`scripts/build-worker.mjs` | 私有站点运行与构建 |

上传会把资料归档到本站服务端，点击生成才将本案件选中材料发送给 DeepSeek。识别线索不等于事实真实或法律适用已经成立，需结合原件复核。当前法律检索限于应用内已核对的条文，完整历史法律版本、地方和行业特别规则仍未覆盖；缺少日期或依据时明确标记待核验，详见[法律条件核对说明](docs/LEGAL_REVIEW.md)。企业系统对接、正式诉讼文书和Word导出仍未实现；现有文本导出与沟通草稿继续可用。
